# Tarefas Projeção - Backend

Este é o backend do sistema de gestão de tarefas do UniProjeção. Implementado em Java com o framework Spring Boot.

## 🎯 Objetivo

Gerenciar tarefas, usuários, cursos e disciplinas de forma eficiente, servindo dados via API REST para o frontend Angular.

Dependências e tecnologias: 
openjdk version "21.0.3" 2024-04-16 LTS
OpenJDK Runtime Environment Temurin-21.0.3+9 (build 21.0.3+9-LTS)
OpenJDK 64-Bit Server VM Temurin-21.0.3+9 (build 21.0.3+9-LTS, mixed mode, sharing)

springboot          3.4.5
dependências springboot starterdata.jpa, java web,springboot devtools, mysqlconector, lombok, springboot startertest 

## 🛠️ Como executar

1. Clone o repositório:

git clone https://github.com/antonio-samuel/tarefas-projecao-backend.git

 2. Importe o projeto em sua IDE (IntelliJ, Eclipse, Vscode, entre outros) como projeto Maven.

3. Execute a classe: com.projecao.tarefas.TarefasProjecaoBackendApplication

4. Acesse o backend em: http://localhost:8080


## 🔧 Endpoints disponíveis

- `/usuarios`
- `/cursos`
- `/disciplinas`
- `/tarefas`
